# Abartılı Çay Molası Motoru

## Bu Ne Lan?

Bu proje, insanlık tarihinin en büyük sorununu çözmek için yaratılmıştır: **Çay molasının asla bitmemesi**.

Evet, doğru duydunuz. Modern dünyada herkes çalışıyor, kod yazıyor, commit atıyor. Ama kimse çay molasının kutsallığını anlamıyor. Bu motor, çay molasını bilimsel bir kesinlikle sonsuza kadar uzatır.

## Nasıl Çalışır?

1. Programı çalıştırın.
2. Çay demlenir (simüle edilir).
3. Molaya çıkılır.
4. Asla geri dönülmez.
5. Üretkenlik %0 olur. Bu bir bug değil, özelliktir.

## Kurulum

```bash
git clone https://github.com/Tentivory/abartili-cay-molasi-motoru.git
cd abartili-cay-molasi-motoru
python cay_molasi.py
```

Python 3.x yeter. Bağımlılık yok. Hayat zaten yeterince karmaşık.

## Özellikler

- Rastgele çay türleri önerir (rize, çaykur, vs.)
- Molayı uzatmak için sonsuz döngü kullanır
- Her 10 saniyede bir "biraz daha içeyim" der
- Üretkenlik hesaplar ve her seferinde 0 çıkar
- Ciddi görünür ama tamamen saçmadır
